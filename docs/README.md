# Flagcel Documentation

This directory contains the detailed project docs that are intentionally kept out of the root README.

- [Configuration](configuration.md) - environment variables and runtime settings.
- [Authentication](auth.md) - local admin auth, OIDC SSO, sessions, and API keys.
- [API](api.md) - OpenAPI spec and live API docs.
- [SDKs](sdks.md) - Go, JS/TS, and Python OpenFeature providers.
- [Web UI](web-ui.md) - dashboard development and production builds.
- [Migrations](migrations.md) - database schema migration workflow.
- [Development](development.md) - local development commands and prerequisites.

Runnable SDK examples live in [`../examples`](../examples).
